# Desktop Todo

一款常驻 Windows 桌面的半透明待办卡片，通过 **CalDAV 协议**与 **Nextcloud Tasks** 同步。PC 上随手记，手机上用 Nextcloud Tasks 接着看。

## 它能做什么

- 桌面置顶卡片：无边框、可拖动、可缩放、贴边吸附，5 套主题，默认隐藏已完成任务
- 任务增删改、勾选完成、右键设优先级（红高 / 橙中 / 蓝低）
- 与 Nextcloud Tasks 双向同步，添加 / 编辑 / 完成 / 删除 / 优先级变更立即写回服务器
- 不在任务栏显示按钮，只在右下角系统托盘常驻图标；「×」只隐藏窗口，不会结束程序

## 快速开始（推荐：下载 Release）

### 1. 下载并解压

到 [Releases 页面](https://github.com/lingting0/desktop-todo-wpf/releases/latest) 下载 `DesktopTodo-v1.0.0-win-x64.zip`，解压到任意普通文件夹（不要放进需要管理员权限的目录，例如 `C:\Program Files`）。

**解压即用，没有安装向导**：双击 `DesktopTodo.exe` 即可。

### 2. 装一次运行时

Windows 不自带 .NET 8，需要先安装 [**.NET 8 Desktop Runtime**](https://dotnet.microsoft.com/download/dotnet/8.0)。装一次即可，之后升级程序不用重装。

> 如果双击 exe 没反应或提示缺少运行时，基本都是这一步没做。

### 3. 首次配置

1. 点标题栏的 **⚙（设置）**
2. 填写 **Nextcloud URL**、**用户名**、**应用密码**（密码框为遮蔽输入）
3. 点 **「测试连接」**——用当前填写的值实际连一次服务器，返回日历名与任务数；此步不落盘、不影响现有连接
4. 成功后点 **「保存」**

保存后**设置立即生效**：自动重建同步连接、按新间隔重置定时器并重新拉取任务，**不用重启程序**。

应用密码在 Nextcloud 网页端生成：**设置 → 安全 → 设备与会话 → 创建新应用密码**，不要填账号登录密码。

### 4. 日常使用

- 「×」或「─」：隐藏窗口，程序继续在后台同步
- 双击托盘图标（或右键「显示/隐藏」）：把卡片叫回来
- 右键托盘 →「退出」：**唯一**真正结束进程的方式

## 运行要求

| 项 | 说明 |
|---|---|
| 操作系统 | Windows（x64） |
| 运行时 | **.NET 8 Desktop Runtime**，Windows 不自带，需单独安装 |
| 服务端 | 一个可用的 Nextcloud，且已启用 **Tasks** 应用 |
| 网络 | 推荐 `https`；`http` 也能用，但凭据会明文传输（见下文） |
| 依赖 | 零 NuGet 包；发行包解压即用，不需要安装程序 |

## 发行包里有什么

| 文件 | 作用 |
|---|---|
| `DesktopTodo.exe` | 程序入口，双击运行 |
| `DesktopTodo.dll` / `DesktopTodo.deps.json` / `DesktopTodo.runtimeconfig.json` | 运行必需 |
| `ToDoIcon.ico` / `ToDoIcon.png` | 托盘与窗口图标 |
| `config.example.json` | 配置模板，全是占位值，**不含任何凭据** |
| `README.md` | 本说明 |

**发行包不含**：`config.json`（真实运行配置）、任何密码或密钥、调试符号 `.pdb`。程序会在 exe 同目录自行维护 `config.json`，请勿把含真实服务器地址的配置打包分发。

## 设置项

| 项 | 说明 |
|---|---|
| Nextcloud URL | 例：`https://nc.example.com:8443/remote.php/dav/` |
| 用户名 | Nextcloud 账号名 |
| 应用密码 | 在 Nextcloud「设置 → 安全 → 设备与会话」生成；**保存在 Windows 凭据管理器** |
| 日历名称 | 按名称选用支持 VTODO 的日历；留空时回退到任务数最多的日历 |
| 同步间隔（秒） | 最小 30；保存后立即按新间隔重建定时器 |
| 自签证书 SHA-256 指纹 | 可选。留空 = 系统严格校验；填入后只信任该指纹对应的证书 |
| 主题 | 暗黑 / 亮白 / 深蓝 / 墨绿 / 暗紫 |
| 开机自启 | 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |

## 凭据与隐私

- 应用密码存放在 **Windows 凭据管理器**（控制面板 → 凭据管理器 → Windows 凭据，目标名 `DesktopTodo/Nextcloud/...`），**不写入 `config.json`，也不进入发行包**。`config.json` 只保存 URL、用户名和界面偏好。
- 旧版配置里若还带 `app_password`，新版启动时会把它迁移到凭据管理器，成功后从 JSON 中删除。由于该密码曾以明文出现在多处，**迁移后仍建议到 Nextcloud 后台吊销并重新生成**。
- 未处理异常写入 `%LOCALAPPDATA%\DesktopTodo\error.log`，界面只显示简短提示，不弹完整堆栈。

### 关于 TLS 与 http

| 场景 | 行为 |
|---|---|
| `https` + 有效证书 | 系统严格校验，正常连接 |
| `https` + 自签 / 无效证书 | 默认**拒绝**；在设置里填入该证书 SHA-256 指纹后才信任，且只信任这一张（证书固定） |
| `http://` | 不走 TLS，**可以正常使用**，但应用密码会明文经网络传输，仅建议在内网可信环境临时使用 |

证书指纹可在浏览器查看证书详细信息 →「指纹 (SHA-256)」，填入时去掉冒号与空格。

## 同步行为与已知限制

- 定时全量拉取；本地的添加 / 编辑 / 完成 / 删除 / 优先级变更立即写回服务器。
- 使用 **ETag + `If-Match` / `If-None-Match`** 做乐观并发；遇到 412 会提示「已被其他设备修改」，不会静默覆盖。
- 写回时以服务端原始 VTODO 为底稿，只替换本程序管理的字段，保留 `DESCRIPTION`、`CATEGORIES`、`DUE`、`X-*` 等未知属性。
- 写操作失败会在状态栏提示，任务不会被静默隐藏或丢弃。
- **已知限制**：目前没有离线队列，断网时列表为空且写操作会提示失败；恢复后下一次定时同步会拉取最新数据。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 exe 没反应 | 先装 .NET 8 Desktop Runtime |
| 「测试连接」提示认证失败 | 检查 URL、用户名、应用密码；确认用的是**应用密码**而非登录密码 |
| 自签证书连不上 | 在设置里填证书 SHA-256 指纹；不要留空硬连 |
| 用 http 时提示警告 | 属预期：能连，但凭据明文传输，建议改 https |
| 点「×」后程序还在 | 设计如此，托盘图标还在；要彻底结束请右键托盘 →「退出」 |
| 找不到窗口 | 双击托盘图标，或右键 →「显示/隐藏」 |
| 想换账号 / 重置配置 | 设置页改后保存即可；如需清空凭据，到 Windows 凭据管理器删掉 `DesktopTodo/Nextcloud/...` 条目 |
| 改了设置没生效 | 当前版本保存即生效；若仍异常，用托盘退出后重新打开 |

## 从源码构建

需要 **.NET 8 SDK**，在仓库根目录运行 `build.bat`：

- 先清空旧的 `publish`（避免旧 dll / 旧 `config.json` 残留），再 `dotnet publish`
- 逐步检查返回码，失败时不再打印成功信息
- 输出**不包含 `config.json`**；脚本优先使用用户级 SDK（`%USERPROFILE%\.dotnet\dotnet.exe`，无管理员权限时的安装位置），否则用 PATH 中的 `dotnet`
- `build.bat --no-pause` 可用于自动化构建

请勿手工把 `config.json` 放进 `publish` 目录，也不要把含凭据的文件打包分发。
